# Signature blanche — Léa Dulac

Cadre de **400 × 150 px**, mêmes éléments et mêmes positions que la version sombre. Fond blanc, textes, séparateur et logos en **#292929**. Le visuel coloré du nom est conservé. Ombre portée discrète : 0 2px 7px, gris #292929 à 16 %.

- index.html : aperçu local.
- signature.html : HTML à ouvrir dans le navigateur puis copier dans les paramètres de signature de la messagerie. Les images ont des URL GitHub absolues.
- signature-lea-dulac.png : 400 × 150 px.
- signature-lea-dulac@3x.png : 1200 × 450 px, à afficher en 400 × 150 px.
- apercu-avec-ombre.png : aperçu avec 12 px de marge autour du cadre pour montrer toute l’ombre (424 × 174 px). Les exports stricts sont limités aux dimensions du cadre.

L’ombre et les arrondis dépendent du support CSS de la messagerie. Les liens du téléphone, de l’adresse e-mail et du site sont conservés dans la version HTML.
